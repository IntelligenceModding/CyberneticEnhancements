<h1 align="center">Support for Cybernetic Enhancements</h1>

## Alpha Status

**Everything is subject to change. Game-breaking changes, world-breaking changes, and incompatible saves are possible between releases.** Back up worlds before updating and use a disposable world to reproduce destructive bugs. Alpha status does not mean save problems should go unreported.

## Installation and Gameplay Help

This gameplay branch targets Minecraft 1.21.1 with NeoForge. Install the mod on both client and server for multiplayer. JEI is optional. Check the [README](README.md) for features and controls, and the in-game archive for cyberware and quest information.

For installation questions, modpack setup, gameplay questions, and help determining whether something is a bug, use the [Intelligence Modding Discord](https://discord.intelligence-modding.de/).

## Bug Reports

Open the [Bug Report form](https://github.com/IntelligenceModding/Cybernetic-Enhancements/issues/new?template=bug_report.yml). Include:

- Minecraft, NeoForge, and Cybernetic Enhancements versions.
- Singleplayer, LAN, or dedicated-server environment; include both client and server versions for multiplayer problems.
- Steps to reproduce, expected behavior, and actual behavior.
- Relevant implants, abilities, NPC type, contract type, cache tier, station, or banking action.
- Whether the world is new or updated from an earlier alpha, and what world or player data was affected.
- Relevant logs or crash reports, other mods, resource packs, and screenshots where useful.

Logs normally live in the game's `logs/` directory and crash reports in `crash-reports/`. For multiplayer problems, server logs may be needed as well as client logs. Remove private information before sharing. Do not publicly upload a personal world or disclose a live server's credentials.

If you cannot safely reproduce a destructive issue, report the available evidence and say that reproduction has not been attempted. Keep a backup of the affected save.

## Feature and Version Requests

Use the [Feature Request form](https://github.com/IntelligenceModding/Cybernetic-Enhancements/issues/new?template=feature_request.yml) for cyberware, NPC, dialogue, quest, puzzle, progression, interface, and compatibility suggestions.

Use the [Version Support form](https://github.com/IntelligenceModding/Cybernetic-Enhancements/issues/new?template=version_support.yml) for another Minecraft version or loader. Check [repository branches](https://github.com/IntelligenceModding/Cybernetic-Enhancements/branches) and [releases](https://github.com/IntelligenceModding/Cybernetic-Enhancements/releases) first. A request does not guarantee support or a release date.

## Development and Community

See [CONTRIBUTING.md](CONTRIBUTING.md) for setup, data generation, tests, and pull requests. Follow the [Code of Conduct](CODE_OF_CONDUCT.md) in project spaces.

## Private Reports

Report security-sensitive issues privately to **report AT intelligence-modding DOT de**, rather than posting exploit details publicly. Include affected versions, reproduction information, and potential impact. Examples include a remotely triggerable server crash, unauthorized player-data changes, or exploitable payment handling.

Use the same private contact for conduct reports, as described in the [Code of Conduct](CODE_OF_CONDUCT.md).
